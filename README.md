# Stock Forecasting — Lab 2

PyTorch RNN, LSTM and GRU forecasting for Apple (AAPL). The required deliverable is a Jupyter notebook stored in this repository; the user does not need to edit it manually.

## GitHub-only workflow
Changes and validation run through GitHub. The Actions workflow checks notebook structure and dependencies on each push. Full training and end-to-end notebook execution are **not yet implemented or verified**.

## Required scope
Five or more years of OHLCV, chronological train/validation/test, training-only scaling, univariate and multivariate configurations, last-value and moving-average baselines, early stopping, checkpoints, LR scheduler, walk-forward validation, required charts, residual analysis and reproducibility notes.

## Current status
Dependencies and validation automation created. Notebook integration, training pipeline and real experiment results are pending.
